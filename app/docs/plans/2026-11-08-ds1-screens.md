## Global Constraints

* 작업 디렉터리는 `app/`. 브랜치 `app/ds1-screens`. 모든 명령은 `app/`에서 실행합니다.
* 생성물(`lib/core/api/gen/**`, `lib/core/ia/gen/ia.g.dart`, `lib/core/l10n/arb/*`, `lib/core/l10n/gen/**`, `lib/design/tokens/gen/tokens.g.dart`)은 생성기로만 바꿉니다: `dart run tool/gen_ia.dart`, `dart run tool/import_writing_arb.dart && flutter gen-l10n`, `tool/gen_api.sh`, `dart run tool/gen_tokens.dart`.
* 사용자에게 보이는 글자는 ARB 키로만 냅니다. 새 임시 키를 만들지 않습니다(필요한 키는 모두 ARB에 있음). 긴 대시, 범위 대시, 가운뎃점을 쓰지 않습니다(D93).

* 계약 파일을 읽는 테스트에는 `@Tags(['contract'])`를 붙입니다(`test/contract/contract_tags_test.dart`가 대조).

* 코드 주석과 테스트 이름은 한국어. `dynamic`/`Object?` 남용 금지. 공개 위젯은 `const` 생성자.
