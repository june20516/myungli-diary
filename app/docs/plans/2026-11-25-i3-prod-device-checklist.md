# I3 prod 리허설 실기기 확인 목록 (#1282 ③, D139)

prod 설정 빌드(빌드 12, Play 내부 테스트와 TestFlight 내부 테스터)로 실기기에서 한 번 끝까지 돕니다.
한 줄에 확인 하나입니다. 되면 `[x]`, 안 되면 `[x]` 대신 `[!]`를 두고 줄 끝에 무엇이 보였는지 적습니다.
`[!]` 줄은 app 세션이 담당 단위로 Issue를 엽니다(사용자를 막는 문제는 `sev:1`).

* **기기:** Android 한 대(Play 내부 테스트로 설치), iPhone 한 대(TestFlight로 설치). 줄 앞 `A`는 Android, `i`는 iPhone, `A i`는 둘 다입니다.
* **이 빌드는 prod입니다:** prod server, 실제 광고 단위, prod SSV, RevenueCat 플랫폼 키입니다. 계정과 일기는 prod 장부에 남습니다(마지막에 계정 삭제로 지웁니다).
* **자동 E2E가 덮은 것(①, 2026-11-25 staging에서 12개 중 10 통과, 2 건너뜀은 설계대로):** 온보딩, 기존 사용자 로그인, 오늘, 달력, 일기, 나의 사주, 문의, 계정 삭제 화면 흐름. 아래 목록은 그때 대역이나 모의로 바꾼 것(로그인 SDK, 결제, 푸시, 광고)과 자동으로 못 덮는 시스템 화면입니다.

- [ ] A: AdMob 콘솔 **설정 → 테스트 기기**에 Android 광고 ID(휴대폰 **설정 → Google → 광고**)를 등록했습니다(반영 1~24시간)
- [ ] i: 같은 곳에 iPhone IDFA를 등록했습니다(IDFA를 보여 주는 앱에서 추적 허용 뒤 확인)
- [ ] A i: 이 확인이 끝날 때까지 **광고를 누르지 않습니다**(등록 전 실제 광고 클릭은 계정 정지 사유)
- [ ] A i: 스토어 sandbox 결제 계정이 준비됐습니다(Play 라이선스 테스터, App Store sandbox 테스터)

- [ ] A i: 카카오톡 앱 로그인이 됩니다
- [ ] A i: 카카오톡 로그인 창에서 취소하면 welcome에 그대로 남고 오류 창이 뜨지 않습니다
- [ ] A i: 카카오계정(웹) 로그인이 되고, 취소도 welcome으로 돌아옵니다
- [ ] A i: LINE 앱 로그인이 되고, 취소도 welcome으로 돌아옵니다
- [ ] A i: LINE 앱을 지운 상태에서 LINE 웹 로그인이 됩니다
- [ ] A i: Google 계정 선택으로 로그인이 되고, 선택 창에서 취소하면 welcome으로 돌아옵니다
- [ ] A i: 로그아웃 뒤 Google로 다시 로그인하면 계정 선택 창이 다시 뜹니다
- [ ] i: Apple 로그인(기기 창)이 되고, 취소하면 welcome으로 돌아옵니다

- [ ] A: Apple 웹 로그인 중 홈으로 나갔다가 앱으로 돌아와도 로그인이 이어지거나 welcome으로 돌아옵니다(멈춘 화면 없음)
- [ ] A: PC에서 `adb shell pm get-app-links app.myungli.diary` 결과에 앱 링크 호스트가 `verified`입니다

## 3. 온보딩과 알림 권한

- [ ] A i: 새 계정은 약관 동의, 호칭, 생년월일, 시간, 성별 입력 뒤 미리보기와 오늘로 갑니다
- [ ] A i: 알림 허락 화면에서 시각을 고르고 허락을 누르면 OS 권한 창이 뜨고, 허용하면 다음으로 갑니다
- [ ] A i: (다른 계정이나 재설치 때) 알림 허락 화면에서 건너뛰기나 OS 권한 거부를 해도 막히지 않고 다음으로 갑니다

## 4. 탭 네 개

- [ ] A i: 오늘: 총운 문장, 카드 네 개, 해시태그가 보이고 카드를 누르면 시트가 펼쳐집니다
- [ ] A i: 일기: 오늘 일기를 쓰고 저장하면 태그 칩이 붙고, 태그를 누르면 같은 태그 목록이 나옵니다
- [ ] A i: 일기: 지난 날짜에 일기를 쓸 수 있습니다
- [ ] A i: 달력: 이번 달 길흉 채우기와 음력, 절기가 보이고 일정을 하나 만들고 지울 수 있습니다
- [ ] A i: 나의 사주: 사주팔자 표와 대운이 보이고, 잠긴 근거에는 잠금 안내가 붙습니다
- [ ] A i: 오늘 카드 공유로 이미지가 OS 공유 창에 넘어갑니다
