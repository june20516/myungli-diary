# 컴포넌트 2.6.0·REST draft.6 따라잡기 Implementation Plan

> **agentic worker에게:** REQUIRED SUB-SKILL: 이 plan을 task 단위로 구현하려면 suberpower:subagent-driven-development(권장) 또는 suberpower:executing-plans를 사용하세요. Step은 추적을 위해 checkbox(`- [ ]`) 문법을 사용합니다.

**Goal:** drift #264(컴포넌트 계약 2.6.0)·#266(REST draft.6)을 맞추고, writing 원고(#237 오류 문구 3개, #232 엔진 안내)를 이어 계획 4의 임시 결정(A35·A37·A40~A44)을 정리합니다.

**Architecture:** 생성물(ARB·REST 클라이언트)을 다시 만들고, 명세가 정한 변형 이름(`date-picker` `solar`, `text-field` `multiline`)을 컴포넌트 API에 드러냅니다. 그날 시트의 화면 안 위젯(`_ScheduleError`)은 `event-row` `failed`라는 design 컴포넌트로 옮겨 재사용합니다. 이미 맞는 구현(풀이 시트 한자, 근거 여럿 쌓기, 윤달 라벨, 1900-02 첫 달, `birthCity` 경도)은 임시 주석과 결정 문장만 확정으로 바꿉니다.

**Tech Stack:** Flutter, Riverpod, flutter_test, golden(Docker `tool/goldens_linux.sh`)

**Spec:** `docs/identity/design/components/`(2.6.0, `calendar.md`·`input.md`·`sentence.md`·`feedback.md`), `server/api/openapi.yaml`(1.0.0-draft.6), design 결정 V36~V38

## Global Constraints

* ARB 문구는 writing 원고를 `dart run tool/import_writing_arb.dart`로만 가져오고 손으로 쓰지 않습니다. app 전용 임시 키는 `@키.description`에 `임시`(A7).
* 생성물(`lib/core/l10n/gen/`, `lib/core/api/gen/`)은 원본에서 다시 만든 그대로 commit합니다.
* `text-field` `multiline`: 최소 높이 52, 최대 6줄 뒤 스크롤, 지우기 아이콘은 첫 줄 높이, 키보드 동작 줄바꿈.
* `date-picker` `solar`: segmented·윤달·확인 줄 없음, 휠·선택 띠·범위(1900-01-31~2099-12-31)는 `birth`와 같음.
* 그날 시트 일기 입구(V37): 보기 = `depth-link` `navigate`, 쓰기 = `primary-button` `filled`. 둘 중 하나만.
* `event-row` `failed`: 오류 종류별 기존 문구 한 줄(`type.caption.lg`, `text.secondary`, 가운데) + "다시 시도" quiet + "일정 추가" quiet.
* 원전 인용: 한글은 문장 글꼴 그대로, 한자만 `font.family.hanja`(`fontFamilyFallback` 맨 앞). ja는 바뀌지 않습니다.
* 윤달 초하루 표지(`leapNewMoon`) 문구는 writing #260 전이라 `M.1` 그대로입니다.
* 아직 writing 문구가 없는 code `city.not_found`·`timezone.invalid`는 대기 목록에 남기고 writing에 키 이름(`errorCityNotFound`·`errorTimezoneInvalid`)을 알립니다(#237 코멘트 답).

## Review Focus

1. 여러 줄 칸에서 기기 글자 2배일 때 지우기 아이콘이 첫 줄과 같은 높이에 있어야 합니다(칸 가운데로 내려가지 않음).
2. `solar` 휠에 음력 값이 들어와도(옛 초안) 양력·윤달 아님으로 보이고, 2월 29일에서 평년으로 해를 바꾸면 28일로 맞춰집니다.
3. 일정만 실패하고 오류가 `AppError`가 아니어도 `failed`는 예기치 못한 오류 문구로 보입니다(빈 줄 금지).
4. A43 임시 키를 지운 뒤 server가 빈 `segments` notice를 보내면 빈 배너 없이 배너를 그리지 않습니다.
5. 원전 상자의 한자 fallback이 ko 한글 글꼴(Gowun Dodum)을 바꾸지 않습니다.
