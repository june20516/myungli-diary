## 현재 진행 순서 (2026-11-27 기준, Play 비공개 테스트 14일 진행 중)
지휘 세션이 상태가 바뀔 때마다 고칩니다. 위 표의 선행 조건을 지금 상태에 대입한 결과입니다. 지난 순서는 [`roadmap-history.md`](roadmap-history.md)에 있습니다.

* **열린 `drift` Issue는 받는 단위의 다음 할 일 맨 앞에 둡니다**(D73, `docs/workflow.md` §6.1). 지금 열린 drift: 없음(2026-11-27).
* **동시에 도는 단위 세션은 둘까지입니다**(D78). 단위 PR은 사용자가 auto-merge를 걸어 두면 검사 통과 때 병합됩니다(D100 ②). CI는 `gh run watch` 없이 60초 이상 간격으로 확인합니다.
* **목표는 T1(비공개 테스트) 통과, 그다음 I4입니다.** Play 비공개 테스트는 2026-11-18 시작했고, 대시보드에 "12명 이상 참여 선택"이 완료로 나옵니다(테스터는 사용자가 유료 테스트 서비스로 모음). 14일이 차면(12월 초) 사용자가 프로덕션 액세스를 신청합니다. 지휘는 Play Console 통계와 대시보드를 하루 한 번 읽어 12 미만이나 신청 버튼 활성화를 알립니다(`tools/play-closed-test/README.md`). T1의 목표는 실제 피드백보다 Play 요건 통과로 두었습니다(사용자, 2026-11-18). Play 요건 면제가 될 수 있는 조직 계정 전환(D-U-N-S)은 확인만 하고 진행하지 않았습니다(내부 `business/research_notes/성장 바이럴 조사`).
* **환경 상태:** staging은 server(REST 1.13.1), 엔진(ruleset 2026.11.9), 결제, SSV, 미리 계산, 아침 알림, O1 알림, 문의 메일, 법적 문서와 지원 페이지까지 배포됐습니다. prod는 D135 최소 구성(최소 0대, `db-g1-small`)으로 떠서 스토어 URL(처리방침, 약관, 지원)을 내줍니다(2026-11-17). prod 승인은 prod에 의미 있는 server 변경만 받고 나머지는 지휘가 취소합니다. staging E2E는 `app/tool/patrol_staging.sh`이고 실행마다 `support@`로 `[E2E]` 메일이 옵니다.
* **I4 2주 전: Cloud SQL tier와 예산 점검(#903, D135 ④, 원래 2026-12-15).** 활성 추이와 L1 결과로 사용자가 정합니다: prod SQL을 `db-g1-small`에서 `db-custom-1-3840` 이상으로 올릴지와 시각(재시작 몇 분), prod 최소 1대 복귀(#817 ④), CPU 과금 방식. 금액은 비공개 L1 리포트(D74).
* **server → app 관문(D138, D110 ⑦):** server CI가 이미 나간 앱 빌드를 깨는 계약 변경을 막습니다(S165, 2026-11-17). 꼭 깨야 할 때만 열린 enum 전환, 최소 지원 버전 올리기(staging과 prod 설정 둘 다), `/v2` 중 하나로 갑니다. app은 최소 버전 안내를 실기기로 확인합니다(#1258).
* **브랜치 분리(D141) 시행(2026-11-20):** 기본 브랜치는 `staging`이고, prod(`main`)에는 지휘의 승격 PR만 들어갑니다. 단위 몫 app #1285, design #1286은 끝났고 core #1287이 남았습니다(다음 세션을 열 때 `origin/staging` 기준). core 열린 요청이 #1287, #1338, #1255, #59로 쌓여 있어 core 세션 한 번에 묶습니다.
* **유입과 웹(D143, D144, 2026-11-25):** 출시 빌드에 광고 측정 코드를 넣지 않고 유료 광고는 신규 크레딧 범위에서만 씁니다(계정은 I4 때, E24 #1319). 랜딩, 바이럴 셀프 테스트, 어드민을 담는 새 단위 `web/`의 시점은 D145(랜딩 I4 전, 첫 테스트 출시 직후~신년, 어드민 웹 출시 뒤, 그 전 데이터 지원은 server 운영 명령 #1321)입니다. 랜딩은 2026-11-26 prod에 떴습니다(`myungli-diary.app`, 승격 #1383). 운영 API(D145 ⑦, server #1321)는 staging과 prod 모두 준비가 끝났습니다(2026-11-27, E26).
