## 생성 코드
* proto에서 생성한 코드는 사용하는 서비스마다 자기 디렉터리에 commit합니다(D33).

  * server: `server/internal/gen/enginev1/` (server P3에서 생성, Issue #63)
* 생성 코드가 원본 proto와 맞는지는 각 서비스의 CI가 검사합니다.
