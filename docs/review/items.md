# 검수 피드백 항목 대장

검수와 폴리싱 피드백을 "한 화면, 한 문제" 단위로 정리한 대장입니다. 절차는 [`README.md`](README.md), 설계는 [spec](../specs/2026-10-28-review-feedback-design.md)에 있습니다. 고치는 쪽은 지휘입니다.

* 상태: `받음` → `확인 중` → `보냄` → `끝남`. 그 밖에 `보류`(이유를 문제 칸 끝에), `합침`(작업 칸에 `→ F-<번호>`), `버림`(사용자 철회)
* 심각도: `S1` 막힘(기능이 안 되거나 틀린 정보), `S2` 불편(쓰기 어렵거나 헷갈림), `S3` 다듬기(보기, 말투, 세부)
* 원요청 칸은 링크 없이 "비공개 기록 `review/inbox/<파일>` #<n>"으로 적습니다(원요청은 비공개 내부 저장소, D74). 개인 정보는 이 표에 옮기지 않습니다.
* 표는 번호 순서로 쌓고 행을 지우지 않습니다. 루트 docs 검사가 형식을 확인합니다.
