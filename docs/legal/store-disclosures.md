# 스토어 개인정보, 등급 양식 답안

Google Play Console "앱 콘텐츠"와 App Store Connect "앱 개인정보 보호", "연령 등급"에 넣을 답안입니다. 근거는 수집 대장 [`data-inventory.md`](data-inventory.md)와 SDK 공식 안내이고, 수집 대장이나 SDK가 바뀌면 같이 고칩니다(D86 ⑧, E16). 사용자가 콘솔에서 입력합니다. 2026-11-13 작성.

* SDK 근거: AdMob [iOS 데이터 공개](https://developers.google.com/admob/ios/privacy/data-disclosure)(충돌 로그, 성능 데이터, 기기 ID, 광고 데이터, 대략적 위치, 사용자 상호작용), AdMob [Play 데이터 공개](https://developers.google.com/admob/android/privacy/play-data-disclosure)(IP 주소, 사용자 상호작용, 진단 정보, 광고 ID와 앱 세트 ID를 수집, 공유. 목적 광고, 분석, 부정 행위 방지), Firebase [Play 데이터 공개](https://firebase.google.com/docs/android/play-data-disclosure)(Crashlytics 비정상 종료 기록과 설치 UUID, FCM과 App Check는 서비스 제공 목적, 하위 처리자 말고는 제3자에게 넘기지 않음).
* **수집**은 기기 밖으로 보내는 것, **공유**는 서비스 제공자(위탁) 말고 다른 회사에 넘기는 것입니다. Google Cloud, Firebase, RevenueCat, Resend는 위탁이라 공유가 아니고, AdMob은 Google이 독자 책임자라 공유입니다(대장 "처리위탁과 국외 이전").

## Google Play 데이터 보안

공통 답: 모든 데이터는 전송 중 암호화(예). 사용자가 데이터 삭제를 요청할 수 있음(예, 앱 설정 > 계정 삭제와 문의). 

| 범주 > 유형 | 수집 | 공유 | 필수/선택 | 목적 | 출처 |
| --- | --- | --- | --- | --- | --- |
| 개인 정보 > 이름 | 예 | 아니요 | 필수 | 앱 기능, 개인 맞춤 | 호칭 |
| 개인 정보 > 이메일 주소 | 예 | 아니요 | 선택 | 개발자 커뮤니케이션(문의 답장) | 문의 |
| 개인 정보 > 사용자 ID | 예 | 아니요 | 필수 | 앱 기능, 계정 관리 | 계정 id, 로그인 수단 식별자 |
| 개인 정보 > 기타 정보 | 예 | 아니요 | 필수 | 앱 기능, 개인 맞춤 | 생년월일시, 성별, 출생 시간대, 출생 도시(선택) |
| 금융 정보 > 구매 기록 | 예 | 아니요 | 선택 | 앱 기능 | 광고 제거권 구매 |
| 위치 > 대략적인 위치 | 예 | 예 | 필수 | 광고 또는 마케팅, 분석, 사기 예방 | AdMob이 IP 주소로 추정 |
| 앱 활동 > 앱 상호작용 | 예 | 예 | 필수 | 앱 기능, 광고 또는 마케팅, 분석, 사기 예방 | 문장 반응(앱 기능), AdMob 광고 상호작용 |
| 앱 활동 > 기타 사용자 생성 콘텐츠 | 예 | 아니요 | 선택 | 앱 기능 | 일기, 일정, 문의 내용 |
| 앱 정보 및 성능 > 비정상 종료 로그 | 예 | 아니요 | 필수 | 분석 | Crashlytics |
| 앱 정보 및 성능 > 진단 | 예 | 예 | 필수 | 분석, 광고 또는 마케팅, 사기 예방 | Crashlytics 기기 정보, AdMob 진단 |
| 기기 또는 기타 ID | 예 | 예 | 필수 | 앱 기능, 광고 또는 마케팅, 분석, 사기 예방 | FCM 토큰, Firebase 설치 ID, 광고 ID, 앱 세트 ID |

수집하지 않음: 정확한 위치, 주소, 전화번호, 인종, 정치나 종교, 성적 지향, 결제 수단 정보(스토어가 처리), 사진, 동영상, 오디오, 파일, 캘린더, 연락처, 웹 기록, 건강, 메시지.

**계정 삭제 URL(필수):** 계정을 만들 수 있는 앱은 앱 밖에서 삭제를 요청할 수 있는 웹 주소를 내야 합니다. 개인정보 처리방침 주소(9항에 앱 안 삭제 경로와 메일 요청 방법이 있음)를 넣습니다. 처리방침 주소: `https://<서비스 도메인>/legal/privacy?lang=ko`.

## Google Play 앱 콘텐츠의 다른 항목

| 항목 | 답 |
| --- | --- |
| 개인정보처리방침 | 위 처리방침 주소 |
| 앱 액세스 | 일부 기능에 로그인이 필요함. 심사자는 Google 로그인으로 직접 가입할 수 있음을 적고, 첫 풀이는 로그인 없이 볼 수 있다고 적음 |
| 광고 | 예, 광고 포함 |
| 광고 ID | 예, 사용. 목적: 광고 또는 마케팅, 분석, 사기 예방(AdMob) |
| 콘텐츠 등급(IARC 설문) | 폭력, 성적 콘텐츠, 욕설, 도박, 약물 없음. 사용자끼리 소통하거나 콘텐츠를 공유하는 기능 없음(일기는 본인만 봄). 위치 공유 없음. 디지털 구매 있음 |
| 타겟층 | 16~17세, 18세 이상(D127: 만 14세 이상이지만 Play 구간에 14세가 따로 없어 13~15세를 고르면 만 13세까지 대상으로 보임) |
| 뉴스 앱, 코로나19, 정부 앱, 금융 기능, 건강 | 해당 없음 |
| 데이터 보안 | 위 표 |

## App Store 앱 개인정보 보호

Apple 기준으로 **추적**은 다른 회사 앱이나 웹의 데이터와 엮어 광고에 쓰는 것입니다. AdMob이 ATT 허용 시 광고 ID(IDFA)로 맞춤 광고를 하므로 "추적에 사용됨"이 있습니다.

| 데이터 유형 | 사용자와 연결 | 추적 | 목적 |
| --- | --- | --- | --- |
| 연락처 정보 > 이름 | 예 | 아니요 | 앱 기능 |
| 연락처 정보 > 이메일 주소 | 예 | 아니요 | 앱 기능(문의 답장) |
| 사용자 콘텐츠 > 기타 사용자 콘텐츠 | 예 | 아니요 | 앱 기능(일기, 일정, 반응) |
| 사용자 콘텐츠 > 고객 지원 | 예 | 아니요 | 앱 기능(문의) |
| 식별자 > 사용자 ID | 예 | 아니요 | 앱 기능 |
| 식별자 > 기기 ID | 예 | 예 | 제3자 광고, 분석, 앱 기능(알림) |
| 구입 항목 > 구입 내역 | 예 | 아니요 | 앱 기능 |
| 위치 > 대략적인 위치 | 아니요 | 예 | 제3자 광고, 분석 |
| 사용 데이터 > 제품 상호작용 | 예 | 아니요 | 분석, 앱 기능 |
| 사용 데이터 > 광고 데이터 | 아니요 | 예 | 제3자 광고 |
| 진단 > 충돌 데이터 | 아니요 | 아니요 | 앱 기능, 분석, 제3자 광고(AdMob SDK 충돌 기록) |
| 진단 > 성능 데이터 | 아니요 | 아니요 | 분석, 제3자 광고(AdMob 앱 실행 시간, 응답 멈춤 빈도 등) |
| 진단 > 기타 진단 데이터 | 아니요 | 아니요 | 분석, 앱 기능 |
| 기타 데이터 | 예 | 아니요 | 앱 기능(생년월일시, 성별, 출생 시간대, 출생 도시) |

## App Store의 다른 항목

| 항목 | 답 |
| --- | --- |
| 개인정보 처리방침 URL | 위 처리방침 주소 |
| 연령 등급 | 모든 항목 "없음". 운세는 도박이 아님. 사용자 생성 콘텐츠는 본인만 보며 공유되지 않음. 결과 등급은 콘솔이 정함 |
| 심사 정보 | 데모 계정 없음. "Apple로 로그인으로 가입해 모든 기능을 쓸 수 있음, 첫 풀이는 로그인 없이 가능"이라고 적음 |
| 수출 규정(암호화) | 표준 HTTPS만 사용, 면제 대상 |
| 앱 추적 투명성 | AdMob 맞춤 광고에 ATT 요청을 띄움(D53 ④) |

## 확인 필요

* 계정 삭제 URL로 처리방침 주소를 쓰는 것은 Play 정책상 허용되는 형태(앱 이름, 삭제 단계, 지우는 데이터와 보관 기간이 보이는 웹 페이지)로 보았습니다. 심사에서 반려되면 server가 전용 페이지를 둡니다.
