# ja 근거 용어집 (D70)

명리 용어의 일본어 표기를 **출처로 정하는** 자료입니다. 일본어 감수자 없이도 표기를 믿을 수 있게, 용어마다 공신력 있는 출처의 원문을 모으고 신뢰도는 규칙으로 계산합니다. 고치는 쪽은 지휘 세션이고, writing은 이 자료를 근거로 glossary ja(`docs/identity/writing/slots/content/glossary.yaml`)를 씁니다.

* 배경: 일본 시장 조사(비공개 기록 `business/reports/일본 사주추명 시장 유효성 검토.md`), 결정 D70·D71
* 검사: `python3 -I tools/docs-check/docs_check.py .` (ci-gate `docs` job). 형식과 신뢰도 계산을 확인합니다.

## 파일
용어군마다 JSON 파일 하나입니다. 파일마다 `sources`(출처)와 `terms`(용어)를 둡니다. 출처 id는 모든 파일에서 하나뿐이어야 하고, 다른 파일의 출처를 근거로 걸 수 있습니다.

| 파일 | 용어군 |
| --- | --- |
| `chart.json` | 술법·명식 구조: 四柱推命, 命式, 年干…時支, 蔵干 자리, 干支, 大運·歳運, 節入り, 子の刻, 旧暦 |
| `stems-branches.json` | 五行, 十干, 十二支, 행운 색(자체 용어) |
| `ten-gods.json` | 通変星 10개와 묶음 5개 |
| `hidden-stems-stages.json` | 蔵干과 本気·中気·余気, 十二運 12개, 身強·身弱, 用神·喜神·忌神, 調候, 格局 |
| `shinsal-relations.json` | 神殺 6개, 空亡, 干合·支合·冲·刑 등, 날의 성격(자체 용어) |

## 출처
| 필드 | 값 |
| --- | --- |
| `id` | 소문자·하이픈. 예: `kotobank-nipponica-shichusuimei` |
| `kind` | 아래 등급표의 종류 |
| `publisher` | 발행처(출판사, 학회, 운영 회사, 개발자). **독립성은 발행처로 셉니다.** 같은 발행처는 파일이 달라도 같은 문자열로 적습니다(같은 저자의 여러 학회는 하나로 셈. 예: `高木乗（命理学会・高木綜合運命学会）`) |
| `title`, `url`, `accessed` | 제목, 주소, 확인한 날(YYYY-MM-DD) |

| 등급 | `kind` | 예 |
| --- | --- | --- |
| A | `dictionary` | コトバンク의 사전(日本大百科全書·大辞林·大辞泉·世界大百科事典·日本国語大辞典), 국어사전. コトバンク에 실려도 발행처가 점술 학교인 용어집(『占い用語集』, 占い学校 アカデメイア・カレッジ)은 `school`입니다 |
| A | `book` | 출판된 四柱推命 책(국립국회도서관 서지·목차·디지털 컬렉션 본문 포함) |
| A | `academic` | 논문·대학 기요(CiNii, J-STAGE) |
| B | `school` | 유파·협회·전문 감정사의 공식 해설 |
| B | `software` | 命式 계산 사이트·전문 소프트웨어의 표시 |
| B | `app` | 스토어에 있는 四柱推命 앱의 화면·설명 |
| C | `media`, `wiki`, `blog` | 일반 매체, 위키백과, 블로그·Q&A |

## 용어
| 필드 | 값 |
| --- | --- |
| `id` | `<범주>.<값>`. glossary 키가 있으면 같은 값을 씁니다. 화면 상위 용어는 `concept.<값>` |
| `ko`, `hanja` | 한국어 이름과 한자 |
| `glossary_key` | glossary.yaml의 키, 없으면 `null` |
| `ja`, `reading` | 권장 일본어 표기와 읽기. 정하지 못했으면 `null` |
| `aliases` | 함께 쓰이는 다른 표기(근거에 나온 것) |
| `coined` | 일본에 대응 용어가 없어 우리가 만든 이름이면 `true`(예: 날의 성격). `note`에 만든 이유를 적습니다 |
| `evidence` | `{source, form, quote}` 목록. `form`은 출처에 실제로 쓰인 표기, `quote`는 그 표기가 나온 원문 한 줄 |
| `confidence` | 아래 규칙으로 계산한 값. 검사가 다시 계산해 다르면 실패합니다 |
| `note` | 한국 관례와 다른 점, 출처끼리 엇갈린 점 |

## 신뢰도 규칙
`ja`와 같은 표기(`form == ja`)를 쓴 근거만 셉니다. `aliases` 표기의 근거는 기록만 하고 세지 않습니다.

| 신뢰도 | 조건 | writing의 쓰임 |
| --- | --- | --- |
| `상` | 서로 다른 발행처 2곳 이상, 그중 A 등급이 1곳 이상 | glossary ja로 바로 씀 |
| `중` | 서로 다른 발행처 2곳 이상(A 없음), 또는 A 등급 1곳 | 근거를 보강한 뒤 씀 |
| `하` | 그 밖 | 쓰지 않음 |
| `자체` | `coined: true` | 제품 이름이라 근거 대신 `note`로 판단 |
| `미정` | `ja`가 `null` | 조사 필요 |

## 현황 (2026-10-15)
용어 136개: 상 113, 중 10, 하 4, 자체 9. `하`는 지장간 자리 이름(年支蔵干·日支蔵干·時支蔵干)과 朝子時이며, 화면에서는 「年支の蔵干」처럼 풀어 쓰는 쪽을 검토합니다. 읽기(`reading`)는 신뢰도 계산에 들어가지 않으므로 writing이 통일합니다(예: 忌神 きじん·いむがみ).

## 근거를 모으는 법
1. 사전(コトバンク)과 출판물(국립국회도서관 디지털 컬렉션의 본문 검색, 서지·목차)을 먼저 찾습니다. 가장 강한 근거입니다.
2. 그다음 일본 命式 계산 사이트·앱의 화면과 유파·감정사 해설을 찾아 독립된 발행처를 늘립니다.
3. 출처가 서로 다른 표기를 쓰면 많이 쓰이는 쪽을 `ja`, 나머지를 `aliases`에 두고 `note`에 적습니다.
4. 표시 관례가 한국과 다른 용어(蔵干을 하나만 표시하는 유파 등)는 표기와 별개로 `note`에 남깁니다. D71 기준 안내의 재료입니다.
