# 조사 표

원본은 `rules/josa.yaml`입니다. 예시는 `표기된 원고 → 렌더 결과`입니다.

| 표기 | 받침 있음 | 받침 없음 | ㄹ 받침 | 예시 |
| --- | --- | --- | --- | --- |
| `(이)가` | 이 | 가 | 이 | 남색(이)가 → 남색이<br>파랑(이)가 → 파랑이<br>丑(이)가 → 丑이<br>★(이)가 → ★이(가)<br>보라(이)가 → 보라가<br>0(이)가 → 0이 |
| `(은)는` | 은 | 는 | 은 | 10(은)는 → 10은<br>100(은)는 → 100은 |
| `(을)를` | 을 | 를 | 을 | 甲(을)를 → 甲을<br>1000(을)를 → 1000을 |
| `(과)와` | 과 | 와 | 과 | A(과)와 → A와<br>100000(과)와 → 100000과 |
| `(으)로` | 으로 | 로 | 로 | 하늘(으)로 → 하늘로<br>동쪽(으)로 → 동쪽으로<br>서(으)로 → 서로<br>L(으)로 → L로<br>★(으)로 → ★(으)로 |
| `(이)에요` | 이에요 | 예요 | 이에요 | 1(이)에요 → 1이에요<br>2(이)에요 → 2예요<br>10000(이)에요 → 10000이에요<br>★(이)에요 → ★(이)에요 |
