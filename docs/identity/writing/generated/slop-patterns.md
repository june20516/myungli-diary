# slop 패턴

원본은 `rules/slop.yaml`입니다. 판정이 `llm`인 규칙은 루브릭으로 사람이 봅니다.

| ID | 이름 | 판정 | 심각도 | 예외 목적 | 탐지식 또는 루브릭 |
| --- | --- | --- | --- | --- | --- |
| slop.P1 | 목적 없는 자리의 과한 추상화 | llm | warn | care | 기능·정보 슬롯에서 무엇이, 어디서, 어떻게인지 말하지 않는 문장인가. 실제로 일어나는 결과를 쓰지 않았다면 해당합니다. |
| slop.P2 | 정의형 소개 | rule | warn | - | regex: `^\S+(은\|는) .+(한\|인) \S+(입니다\|이에요\|예요)[.]?$` (ko) |
| slop.P3 | 사물 주어 의인화 | llm | warn | - | 사주를 아는 일기장처럼 사물이 알고 느끼게 하는 영어식 관계절인가. 사물을 주어로 세워 사람의 행위를 시키면 해당합니다. |
| slop.P4a | 기획 용어 노출 | rule | error | - | lexicon: `사용자, 콘텐츠, 유저` (ko) |
| slop.P4b | 시점 혼재 | llm | warn | - | 한 문장에서 "내"와 "사용자"처럼 화자와 호칭의 시점이 섞이는가. |
| slop.P5 | 번역 슬로건 | rule | warn | - | lexicon: `주인공은, 언제나 당신, 당신만을 위한` (ko) |
| slop.P6 | 자기 성격 형용 | llm | warn | - | 차분하게 알려드려요처럼 톤 규칙을 문장에 꺼내 놓았는가. 성격은 문장으로 드러내야 합니다. |
| slop.P7 | 내용 없는 균형 병렬 | rule | warn | - | regex: `\S+도 \S+도 아닌` (ko) |
| slop.P8 | 들뜬 강조 | rule | error | - | regex: `[!！]\|\p{Extended_Pictographic}` |
| slop.P9 | 문어투·기술 어휘 | llm | warn | - | 말로는 잘 쓰지 않는 문어투 동사("스며드는", "익히기")나 한자어 기술 용어("학습 효율")를 썼는가. 일상에서 말로 쓰는 쉬운 동사·명사(배우기, 잘 맞아요)로 바꿀 수 있으면 해당합니다. 명리 용어 토큰은 대상이 아닙니다. |
