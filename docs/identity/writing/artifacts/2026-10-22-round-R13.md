## R13-1. 사주 요약 줄 (예: 1990. 3. 5., 양력, 오후 2:30)
선택지: 양력 1990. 3. 5. · 오후 2:30 / 1990. 3. 5. 양력 · 오후 2:30(초안) / **양력 1990. 3. 5. 오후 2:30**(선택) / 다 별로

## R13-2. 태어난 시각을 모를 때
선택지: **시각 모름**(선택) / 시간 모름(초안) / 태어난 시각 모름 / 다 별로

## R13-3. 사주 정보가 없는 계정
선택지: 아직 사주를 입력하지 않았어요 / 사주 여정을 아직 시작하지 않았어요(대조군) / **사주 정보 없음**(초안, 선택) / 다 별로

## R13-4. 합치기 최종 확인 창 (R11-4 재출제)
선택지: **두 계정을 합칠까요? 합친 뒤에는 되돌릴 수 없어요.**(선택, R11-4와 같음) / 계정을 합칠까요? 고르지 않은 계정은 지워지고 되돌릴 수 없어요. / 합치면 되돌릴 수 없어요. 계속할까요? / 다 별로
