## 문항과 선택지 (낸 순서 그대로)
**R37-1 색 둘인 날 첫째 칩(내 균형 기준)** `color.balance.*`
1. 내 사주의 균형으로 보면 검정이 잘 맞아요.
2. 내 균형에 맞춰 보면 오늘은 검정이 좋아요.
3. 검정, 흔들리는 오늘을 붙잡아 줄 나만의 색이에요. (대조군)
4. 다 별로

**R37-2 둘째 칩(원전 기준)** `color.source.*`
1. 옛 책의 기준으로는 흰색이 잘 맞아요.
2. 옛 책대로 보면 오늘은 흰색도 어울려요.
3. 다 별로

다시 물음("옛 책" 대신 "원전"): 1. 원전으로 보면 흰색이 잘 맞아요. 2. 원전대로 보면 오늘은 흰색도 어울려요. 3. 다 별로

**R37-3 집중 시간 낮 칩** `focus_time.day`
1. 낮에는 이 시간에 집중이 잘 돼요.
2. 중요한 일은 이 시간에 하면 좋아요.
3. 다 별로

**R37-4 집중 시간 밤 칩** `focus_time.night`
1. 밤에는 이 시간에 집중이 잘 돼요.
2. 밤에 할 일이 있다면 이 시간이 좋아요.
3. 다 별로

다시 물음: 1. 밤에 할 일이 있다면 이 시간이 좋아요. 2. 밤에 중요한 일은 이 시간에 하면 좋아요. 3. 다 별로

**R1-1 다시 묻기(보통날 색 카드)** `color.<날의 성격>`
1. 그대로("오늘은 검정이 잘 맞아요.") 2. 원전으로 보면 오늘은 검정이 잘 맞아요. 3. 다 별로

## 사용자 의견
* R37-2: "옛 책이라는 번역은 별로임. 좋은 번역이 없다면 그냥 한자어를 그대로 쓰는게 낫다." 근거 문장의 "옛 책", "옛 달력"도 "원전", "택일 원전"으로 바꿨습니다. 다시 물었을 때 "원전의 해석에 따르면 오늘은 흰색도 어울려요"를 직접 적었습니다.
* R37-4: "'집중이 잘된다'나 '할 일이 있다면 ~ 좋다'는 특정 속성이 있는 것처럼 들리는데 맞나, 단순히 좋은 시간을 포장한 건가?" 원전(用時法, 論相主, 黃道)은 일을 벌이기에 길한 시간만 말하고 집중 같은 성질은 말하지 않는다고 답했습니다. "집중"은 원전에 없는 포장이라 빼고, 일을 벌일 때를 고른다는 뜻의 문장을 골랐습니다.
