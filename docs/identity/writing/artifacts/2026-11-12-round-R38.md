## 문항과 선택지 (낸 순서 그대로)
**R38-1 색이 둘인 날 시트 맨 위 한 줄** `todayLuckyColorPairIntro`
1. 오늘은 추천 색이 두 개예요 (design 가안)
2. 오늘은 어울리는 색이 두 가지예요
3. 오늘은 행운이 두 갈래로 피어나는 날이에요 (대조군)
4. 다 별로

**R38-2 다시 묻기(R37-1) 첫째 색 풀이** `color.balance.*`
1. 그대로("내 사주의 균형으로 보면 초록이 잘 맞아요.", "내 균형"이 기준 이름처럼 읽힐 수 있음)
2. 보통날과 같은 문장("오늘은 초록이 잘 맞아요.")
3. 다 별로

**R38-3 다시 묻기(R37-2) 둘째 색 풀이** `color.source.*`
1. 그대로("원전의 해석에 따르면 오늘은 흰색도 어울려요.", "원전"이 기준 이름처럼 읽힐 수 있음)
2. 흰색도 잘 어울려요.
3. 오늘은 흰색도 어울려요.
4. 다 별로

**R38-4 낮과 밤 시간 시트 제목** `todayLuckyTimeDayTitle`, `todayLuckyTimeNightTitle`
1. 낮 집중 시간 / 밤 집중 시간 (design 가안, R37-4 판단과 어긋남)
2. 낮 행운 시간 / 밤 행운 시간
3. 낮에 좋은 시간 / 밤에 좋은 시간
4. 다 별로
