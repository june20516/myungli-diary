## 문항과 선택지 (낸 순서 그대로)
**R36-1 미리보기를 이미 쓴 기기의 안내** `previewUsedNotice`
1. 이 기기에서는 첫 풀이를 이미 봤어요. 저장하고 나면 나 탭의 정보 수정에서 바꿀 수 있어요.
2. 첫 풀이는 이 기기에서 한 번만 볼 수 있어요. 정보를 바꾸려면 저장한 뒤 나 탭 정보 수정에서 바꿔 주세요.
3. 이미 운명을 엿보셨네요! 저장하면 새로운 여정이 시작돼요. (대조군, 첫 묻기에만)
4. 이 기기에서 이미 본 첫 풀이예요. 입력한 정보는 저장한 뒤 나 탭의 정보 수정에서 바꿀 수 있어요. (화면 비교 때 더함)
5. 다 별로

**R36-2 질문 떼기 버튼 / 다시 붙이기 링크** `diaryEditGuideRemove`, `diaryEditGuideAttach`
1. 질문 떼기 / 질문 다시 붙이기
2. 질문 없이 쓰기 / 질문 붙이기
3. 다 별로

**R36-3 열림 꼬리표** `evidenceSheetUnlockUntilMidnight`, `evidenceSheetUnlockUntilDate`
1. 자정까지 열림 / {date}까지 열림 (지휘 가안)
2. 오늘 자정까지 열려 있어요 / {date}까지 열려 있어요
3. 프리미엄 해제 완료! 자정까지 (대조군)
4. 다 별로

**R36-4 길흉판정 카드 안내 줄** `daySheetVerdictExpand`, `daySheetVerdictCollapse`
1. 내역 N개 보기 / 접기 (design 가안)
2. 판정 내역 N개 펼치기 / 내역 접기
3. 글자 없이 꺾쇠만 (화면 비교 때 더함)
4. 다 별로

## 사용자 고침과 다시 묻기
* R36-1, R36-4: 처음에 "화면이 필요"하다고 해 화면 비교 페이지를 만들어 다시 물었습니다.
* R36-2: 사용자가 "질문 없이 쓰기 / 질문 추가"를 적었습니다.
* R36-4: 사용자가 "내역 n개 보기 줄 없이 섹션 전체를 누르면 열리도록 하자고 했는데"라고 결정과 어긋남을 짚은 뒤, "내역보기 그냥 넣자. 대신에 n개 빼고 그냥 내역보기"로 정했습니다. IA 역할의 매개변수 `count`는 쓰지 않습니다.
* R36-6: "이걸 갑자기 왜 물어보는거지?" 판정 없이 닫았습니다.

## 정정 (2026-11-11, W65)
R36-2는 잘못 물었습니다. 사용자는 design #929 관문(2026-11-10)에서 뗀 자리 글자를 "무엇을 쓸지 고민인가요?"(권유 톤 옅은 색, 말풍선)로 이미 정했는데, 이 문구를 선택지에 넣지 않았고, 스크린리더만 읽는 떼기 버튼 이름과 화면에 보이는 권유 글자를 한 질문에 묶었습니다. 사용자의 "질문 추가"는 스크린리더 항목으로 답한 것이라, 화면 글자 `diaryEditGuideAttach`는 "무엇을 쓸지 고민인가요?"로 바꾸고 "질문 추가"는 스크린리더 hint `diaryEditGuideAttachHint`로 옮겼습니다.
