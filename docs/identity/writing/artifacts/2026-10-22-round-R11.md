## R11-1. 계정 합치기 제목
선택지: **두 계정을 하나로 합칠까요?**(선택) / 이 수단은 다른 계정에 연결돼 있어요(초안) / 이미 다른 계정에서 쓰는 수단이에요 / 다 별로

## R11-2. 합치면 남는 것과 옮겨지는 것
선택지: 남길 계정을 고르면 그 계정의 사주 정보·호칭·설정을 써요. … / 남는 것: … / 옮기는 것: …(목록형) / **합치면 고른 계정의 사주 정보·호칭·설정이 남아요. 일기는 두 계정 것을 모두 옮기고, 남은 광고 제거 기간은 더해요. 고르지 않은 계정은 지워져요.**(초안, 선택) / 다 별로

## R11-3. 같은 날 일기가 두 계정에 다 있을 때
* 첫 출제: 같은 날 일기가 겹치는 날이 있어요. 그날 일기도 모두 옮겨요. / 같은 날 쓴 일기가 두 계정에 다 있어도 지우지 않고 모두 옮겨요.(초안) / 걱정 마세요! …(대조군) / **다 별로**
* 다시 출제(부정 "지우지 않고"를 빼고 결과만): 같은 날 일기는 쓴 순서대로 함께 놓여요. / **같은 날 쓴 일기도 모두 이 계정으로 옮겨요.**(선택) / 두 계정에 같은 날 일기가 있어요. 합치면 그날 일기가 여러 편이 돼요. / 다 별로

## R11-4. 합치기 최종 확인 창
선택지: 합치면 되돌릴 수 없어요. 계속할까요? / 계정을 합칠까요? 고르지 않은 계정은 지워지고 되돌릴 수 없어요. / **두 계정을 합칠까요? 합친 뒤에는 되돌릴 수 없어요.**(초안, 선택) / 다 별로

## R11-5. 로그인 수단 줄 끝 동작
선택지: 연결 / 연결 해제 · 연동하기 / 연동 끊기(커뮤니티) · **연결하기 / 연결 끊기**(초안, 선택) · 추가 / 해제 · 다 별로

## R11-6. 마지막 남은 수단 안내
* 첫 출제: 마지막 남은 로그인 수단은 연결을 끊을 수 없어요. / 로그인 수단이 하나는 있어야 해서 이 연결은 끊을 수 없어요. / 로그인 수단이 하나뿐이라 연결을 끊을 수 없어요.(초안) / **다 별로**
* 다시 출제(막는 이유 대신 필요한 것·방법): 지금은 이 수단으로만 로그인할 수 있어요. / 다른 수단을 하나 더 연결하면 이 연결을 끊을 수 있어요. / **로그인할 수단이 하나는 남아 있어야 해요.**(선택) / 다 별로

## R11-7. 로그인 수단 화면 첫머리
선택지: 어느 수단으로 로그인해도 같은 계정으로 들어와요. / 연결한 수단 중 어느 것으로 로그인해도 같은 계정이에요.(초안) / **여러 수단을 연결해 두면 어느 것으로든 이 계정에 로그인할 수 있어요.**(선택) / 다 별로

## R11-8. 떼기 확인 창(예: 카카오)
선택지: 카카오 연결을 끊을까요? 일기와 사주 정보는 그대로 남아요. / 카카오 연결을 끊을까요? 끊으면 이 수단으로는 로그인할 수 없어요.(초안) / **카카오 연결을 끊을까요? 연결한 다른 수단으로 계속 로그인할 수 있어요.**(선택) / 다 별로

## R11-9. 오늘 이미 쓴 날의 일기 쓰기 버튼
선택지: **일기 더 쓰기**(선택) / 새 일기 쓰기 / 한 편 더 쓰기(초안) / 일기 한 편 더 쓰기 / 다 별로. 날짜 시트의 이미 쓴 날 버튼도 같은 말("이날 일기 더 쓰기")로 맞췄습니다.

## R11-10. 날짜 시트의 일기 목록 머리
선택지: **이날 쓴 일기 2편**(선택) / 일기 2편 / 이날 일기 2편(초안) / 다 별로

## R11-11. 오행 이름 (R10-9 재출제)
* 선택지: 나무/불/흙/금속/물 / 목/화/토/금/수 / **나무/불/흙/쇠/물**(선택) / 다 별로. R10-9에서는 목/화/토/금/수를 골랐습니다.
* 확인 문항: 문장 안은 목·화·토·금·수, 표 칸만 나무·불·흙·쇠·물 / 어디서나 나무·불·흙·쇠·물(W31 개정) / **어디서나 목·화·토·금·수 유지(이번 선택은 반영하지 않음)**(선택) / 다른 생각. W31 ②는 그대로입니다.
