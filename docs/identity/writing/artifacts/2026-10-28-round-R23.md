## 문항과 선택지 (낸 순서 그대로)

1. 갑, 을, 병, 정 … (한 글자)
2. 갑목, 을목, 병화, 정화 … (오행을 붙임)
3. 첫째 천간 갑, 둘째 천간 을 …
4. 다 별로

**R23-2 합충형 이름** `relation.*`
1. 끌어당김, 맞물림, 부딪힘, 깎임 (대조군, 번역 조어)
2. 천간합, 지지합, 충, 형
3. 간합, 육합, 충, 형
4. 다 별로

**R23-3 오행 목의 뜻** `term.element.wood`
1. 나무처럼 위로 자라고 사방으로 뻗어 가는 성질이에요. 사람에게서는 새로 시작하고 키워 가려는 마음으로 드러나요.
2. 목은 생명력과 성장의 에너지를 상징하는 오행이에요. (대조군)
3. 나무처럼 위로 자라고 사방으로 뻗어 가는 성질이에요. 새로 시작하는 힘이에요.
4. 다 별로

**R23-4 천간 갑의 뜻** `term.stem.gap`
1. 열 개의 천간 가운데 첫째로, 곧게 자라는 큰 나무를 닮았어요. 한번 정한 길을 꾸준히 가는 모습이에요.
2. 목의 첫째 천간으로, 곧게 자라는 큰 나무에 빗대요. 정한 방향으로 꾸준히 밀고 나가는 모습이에요.
3. 곧게 자라는 큰 나무에 빗대는 천간이에요. 정한 방향으로 꾸준히 밀고 나가는 모습이에요.
4. 다 별로

**R23-5 지지 자의 뜻** `term.branch.ja`
1. 쥐띠를 뜻하는 지지예요. 한겨울과 한밤을 가리켜요.
2. 열두 지지의 첫째로, 띠는 쥐예요. 한겨울과 한밤을 가리키고, 수의 기운이 가장 깊은 때예요.
3. 열두 지지의 첫째로, 띠는 쥐예요. 한겨울 밤처럼 고요히 힘을 모으는 때예요.
4. 다 별로

**R23-6 십성 편관의 뜻** `term.ten_god.pyeongwan`
1. 강력한 카리스마와 리더십의 상징으로, 당신을 한 단계 성장시켜 줄 거예요! (대조군)
2. 나를 단련시키는 엄격한 기준과 도전을 뜻하는 기운이에요. 어려움 앞에서 버티는 힘으로 드러나요.
3. 나를 세게 몰아붙이는 압박과 시험을 뜻하는 기운이에요. 어려움을 견디는 배짱과 빠른 결단으로 드러나기 쉬워요.
4. 다 별로

**R23-7 신살 양인의 뜻** `term.shinsal.yangin`
1. 칼날처럼 아주 센 추진력을 뜻하는 신살이에요. 밀어붙이는 힘이 큰 만큼 서두르지 않는 게 좋아요.
2. 칼날처럼 아주 센 추진력을 뜻하는 신살이에요. 마음먹은 일을 끝까지 밀고 가는 힘으로 드러나요.
3. 칼날처럼 아주 센 추진력을 뜻하는 신살이에요. 밀어붙이는 힘이 큰 만큼 다툼이나 다침을 조심해야 해요.
4. 다 별로

**R23-8 천간 계 뜻의 뒷문장** `term.stem.gye` (judge 의심, 오타를 바로잡아 다시 냄)
1. 조용히 스며들어 곁을 살피는 모습이에요.
2. 조용히 곁을 살피는 모습이에요.
3. 작은 틈까지 촉촉하게 적셔 주는 모습이에요.
4. 다 별로

**R23-9 역할 기신의 뜻** `term.role.gisin`
1. 내 사주의 균형을 흐트러뜨리는 오행이에요. 이 기운이 센 때에는 큰일을 벌이지 마세요.
2. 내 사주와 잘 안 맞는 오행이에요. 이 기운이 센 때에는 무리하지 않는 게 좋아요.
3. 내 사주의 균형을 흐트러뜨리는 오행이에요. 이 기운이 센 때에는 서두르지 않는 게 좋아요.
4. 다 별로

**R23-10 십성 묶음 재성의 뜻** `term.ten_god_group.jaeseong`
1. 편재와 정재를 함께 부르는 이름으로, 내가 다루고 얻는 돈과 결과를 뜻해요. 살림, 일의 성과, 현실 감각이 여기에 들어요.
2. 돈과 일의 결과를 다루는 기운이에요. 편재와 정재가 여기에 들어요.

3. 10년마다 바뀌는 큰 흐름이에요. 그 시기에 어떤 기운이 삶의 바탕에 깔리는지 보여 줘요.

## 굳힌 규칙
* W47: 같은 범주의 용어 뜻은 범주마다 한 틀을 씁니다(천간, 지지, 십성 묶음). 천간 이름은 오행을 붙여 씁니다. 센 신살은 조심할 일을 돌려 말하지 않습니다(R23-7). 대조군 문장이 골리면 우려를 알리고 다시 묻습니다.
