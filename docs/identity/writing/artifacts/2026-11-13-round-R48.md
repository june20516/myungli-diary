# 라운드 R48: 행운 색, 방위, 숫자의 오행 관계 문장 (W78)

* 날짜: 2026-11-13 · 진행: writing 세션(터미널) · 판정: 사용자
* 근거: 지휘 #1132(D130: "내 사주에 필요한 기운"은 바탕 오행 하나, 결과 오행이 다르면 관계를 생략하지 않음, 상생은 "생해 주는", 사용자 예문 "내 사주에 필요한 수 기운을 생해 주는 금의 색, 흰색", "수 기운을 생해 주는 금의 방위, 북서쪽"), core #1149(매개변수 `relation` SAME, MO, JA, CHEO, GWI, 메시지 키는 관계별로 나누지 않음, 방위 희신은 모두 MO, 숫자는 첫째 색과 같은 값), D119 ①(변역 자리: 死絶 母, 胎養冠帶衰 妻, 沐浴病 鬼, 墓 子), 근거 `basis.color/shift`(원전과 12운성 자리 설명)
* 화면 모양이 바뀌지 않는 문장 고르기라 글 선택지로 물었고, 중간부터는 대화로 정했습니다.
* 같은 문항 다시 내기: 하지 않았습니다(R45 사용자 요청).

## 진행
1. 첫 질문 R48-1(子, 妻, 鬼 색 카드)에 원전과 12운성 자리를 넣은 안을 추천했고, 사용자가 "이게 1depth의 시트잖아. 원전을 굳이 언급하는건 너무 갔다"고 했습니다. 원전과 자리 설명은 근거 시트가 이미 하므로 카드에서 뺐습니다.
2. 첫 질문 R48-2(숫자)에 사용자가 "수 가운데"는 오행 수와 헷갈린다며 "수 중에서" 또는 "숫자들 중에서"를 쓰라고 했습니다. 모든 숫자 카드와 숫자 이유, 근거를 "숫자 중에서"(근거는 "하도 수 두 개 중에서")로 고쳤습니다.
3. 사용자가 "소통을 좀 해봐"라고 해 질문 창 대신 대화로 막힌 지점(子, 妻, 鬼의 이유는 원전 규칙뿐)을 설명했습니다.
4. 다시 낸 선택지에 사용자가 직접 문장을 줬습니다: "내 사주에 필요한 수의 기운이 오늘은 반대로 읽는 자리에 있어요. 수를 극하는 토의 노랑이 잘 맞아요." writing이 "반대로"는 鬼에만 맞고 子, 妻는 "다르게"가 정확하다고 짚었고, 사용자가 "다르게"를 받았습니다.
5. 숫자 "오늘 색과 같은 … 숫자 중에서"에 사용자가 어긋날 걱정을 했고, writing이 이 문장이 쓰이는 날은 늘 색이 하나이고 숫자 오행은 첫째 색과 같다는 core 계약(D119 ③, #1149)을 들어 걱정이 크지 않다고 답해 받았습니다.
6. 글자 수: 상한 ko 36자(설명 시트 본문 두 줄)를 사용자 안(57~62자)과 writing 안(49~58자), D130 예문(41자)이 모두 넘어, 같은 조건으로 비교한 뒤 사용자 안으로 정하고 design에 상한을 다시 재 달라고 하기로 했습니다(사용자: "응 가자").

## 확정 (ko, 바탕 수 예)
| 관계 | 키 | 문장 |
| --- | --- | --- |
| 母 색 | `color.<날>.mo` | 내 사주에 필요한 수 기운을 생해 주는 금의 색, 흰색이 오늘 잘 맞아요. |
| 子 색 | `color.<날>.ja` | 내 사주에 필요한 수의 기운이 오늘은 다르게 읽는 자리에 있어요. 수가 생해 주는 목의 초록이 잘 맞아요. |
| 妻 색 | `color.<날>.cheo` | … 수가 극하는 화의 빨강이 잘 맞아요. |
| 鬼 색 | `color.<날>.gwi` | … 수를 극하는 토의 노랑이 잘 맞아요. |
| 희신 방위 | `direction.day_kind.ordinary.mo` | 내 사주에 필요한 수 기운을 생해 주는 금의 방위, 북서쪽이 좋아요. |
| 숫자 | `number.<날>.related` | 오늘 색과 같은 금 기운의 숫자 중에서 천간 갑목에 맞춰 1을 골랐어요. |

* 기신의 날은 "내 사주에 필요한" 자리에 "막힌 흐름을 이어 주는"을 씁니다.
* en, ja는 writing이 썼습니다. 상생은 en `generates`, ja 「生じる」("생해 주는"에 맞춤, "낳아 주는"에 해당하는 gives birth to, 生む는 쓰지 않음), 상극은 근거 원문 뜻과 같은 en `overcomes`, ja 「剋す」입니다.
* `mlw judge`: ko, en 子, 妻, 鬼 문장의 "다르게 읽는 자리"를 추상 표현(slop.P1) 의심으로 짚었습니다. 사용자가 고른 문장이라 그대로 둡니다. 자리 이름은 근거 시트에서 봅니다.
