# 라운드 R5 — 빈도 상한

* 날짜: 2026-10-11 · 진행: writing 세션(터미널) · 판정: 사용자

| 문항 | 질문 | 선택지 | 고른 것 |
| --- | --- | --- | --- |
| R5-1 | 하루 화면에 돌봄 문장은 몇 개까지 (헤드라인 + 보조, 예시 A 1개 / B 2개) | 1개까지 / 2개도 괜찮음 / 다 별로 | **2개도 괜찮음** |
| R5-2 | 한 주에 돌봄 문장은 몇 번부터 과한가 (한 주 총운 7~14개, 보통 3~5개가 돌봄) | 3 / 5 / 7 / 상한 없음 / 다 별로 | **7개까지** |
| R5-3 | "괜찮아요"는 한 주에 몇 번까지 | 1 / 2 / 3 / 다 별로 | **다 별로** ("빡빡하다") |
| R5-3 재출제 | "괜찮아요" 반복 기준 | 한 주 4번 / 한 주 5번 / 하루 화면 1번 / 이틀 연속으로만 나오지 않으면 됨 / 다 별로 | **이틀 연속으로만 나오지 않으면 됨** |
| R5-4 | 영어 화면에서 호칭은 한 주 몇 번까지 | 1 / 2 / 3 / 다 별로 | **2번** |

## 반영
* `limit.L2` 돌봄 하루 2, `limit.L3` 돌봄 한 주 7, `limit.L4` 영어 호칭 한 주 2
* `limit.L8` "괜찮아요"는 연속 이틀 창마다 1개 이하(`window: 2`). 하루에 두 번 나와도 경고.
* 결정 **W12**, **W14**
