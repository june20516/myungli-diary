## R2-4. 행운 컬러, 쓰임새를 붙일지
| # | 선택지 | 비고 |
| --- | --- | --- |
| 1 | 오늘은 남색이 잘 맞아요. | 대등 |
| 2 | 옷이나 소품을 고른다면 남색이 좋아요. | 대등 |
| 3 | 남색 옷이나 소품을 하나 챙겨 보세요. | |
| 4 | 오늘은 남색이 잘 맞아요. 옷이나 소품으로 챙겨 보세요. | 반복을 피할 때의 대안 |
| 5 | 다 별로 | |

* 사용자: 1과 2가 대등. 다만 R2-3의 3과 R2-4의 2처럼 같은 화면에서 같은 틀("~를 고른다면 ~가 좋아요")이 반복되면 slop처럼 느껴진다. 그럴 땐 4번 형태가 낫다.

## 굳힌 규칙
* **W7** 정보 카드는 단순형·쓰임새형·두 문장형을 섞어 쓰고, 같은 화면에서 같은 문장 틀을 반복하지 않는다(사용자 직접 기준) → 화면 상한 `limit.L5`(Task 11b 이후).
* **W8** 총운 헤드라인은 짧은 한 문장. 말줄임은 쓰지 않는다(`style.S2`).
* 관찰(1회): 짧은 주제어 뒤 쉼표("오늘은,")는 고르지 않음.
