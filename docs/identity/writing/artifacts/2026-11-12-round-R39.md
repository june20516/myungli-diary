# 라운드 R39: 행운 칩 시트 본문에 내 값과 오늘 값 (W68)

* 날짜: 2026-11-12 · 진행: writing 세션(터미널) · 판정: 사용자
* 근거: #971(검수 회차2 F-051, 행운 칩 설명 시트 문장이 누구에게나 같은 고정 문장), core #970(본문 키 매개변수), D121(앱 근거는 무엇을 보고 골랐는지까지)
* 대상 바로잡기: #971과 server #972는 이유 문장(`explain.today_reason`, `reason.*`)을 고치는 일로 적혀 있었습니다. 그런데 app 행운 칩 시트(`ExplainLucky`)는 제목과 본문(`daily.color`, `daily.direction`, `daily.number`, `daily.focus_time`)만 그리고 이유 문장을 그리지 않습니다(`app/lib/features/today/presentation/today_screen.dart`). core #970도 이유 값을 본문 키의 매개변수로 더했습니다. 그래서 본문을 다시 씁니다. 본문 매개변수는 server가 이미 렌더합니다.
* 상한: 본문은 시트 두 줄, ko 36, en 64, ja 36(`docs/identity/design/lengths.md`). 후보는 가장 긴 값으로 채워 재고 상한 안인 것만 냈습니다. 집중 시간에 R37 문장과 이유를 함께 넣으면 40자, 숫자의 "수 5와 10 가운데"는 38자라 뺐습니다.
* `mlw judge`(ko, en, ja, 세 슬롯): en 기신의 날 색과 방향의 "reconnects a blocked flow"(slop.P1, 무엇이 막혔는지 말하지 않음). 사용자가 고른 문장이 아니라 writing이 옮긴 것이라 "eases the clash in your chart"(통관의 뜻: 내 사주에서 부딪히는 기운 사이를 잇는 오행)로 고쳤고, 다시 돌려 표시가 없습니다.
* 대조군: R39-1 3, R39-2 1, R39-3 3, R39-5 대조군, R39-6 대조군. 골리지 않았습니다.
* 같은 문항 다시 내기: R39-7은 R39-1을 순서를 바꿔 다시 물은 것임을 밝혔고, 같은 문장(3, 처음의 1)을 골랐습니다.
* 묻지 않고 정한 것: 날 종류별 변형은 고른 틀을 따릅니다. 색과 방향의 기신의 날은 바탕 오행이 통관이라 "막힌 흐름을 이어 주는 {오행} 기운"(근거 문장과 같은 말), 방향의 귀인의 날은 "귀인의 날이라 오늘 지지 {지지}의 방위인", 평범한 날은 용신의 날과 같은 문장입니다. 숫자는 날 종류 넷이 같은 문장입니다.

## 문항과 선택지 (낸 순서 그대로)
**R39-1 행운 색 시트 본문(색이 하나인 날)** `color.<날의 성격>`
1. 내 사주에 필요한 토 기운에 맞춰 오늘은 노랑이 잘 맞아요.
2. 토 기운이 오늘 지지에서 장생 자리라 노랑이 잘 맞아요.
3. 내 사주의 기운이 오늘 노랑 속에서 빛을 찾아요. (대조군)
4. 다 별로

**R39-2 행운 방향 시트 본문** `direction.day_kind.*`
1. 남서쪽에서 오늘의 좋은 기운이 당신을 기다려요. (대조군)
2. 내 사주에 필요한 토 기운의 방위라 남서쪽이 좋아요.
3. 새로 가 볼 곳을 고른다면 토 기운의 방위인 남서쪽이 좋아요.
4. 다 별로

**R39-3 행운 숫자 시트 본문** `number.*`
1. 토 기운의 수 가운데 오늘 천간 경금에 맞춰 10을 골랐어요.
2. 오늘은 10이 잘 맞아요. 행운 색과 같은 토 기운의 수예요.
3. 10이라는 숫자에 오늘 토 기운이 깃들어 있어요. (대조군)
4. 다 별로

**R39-4 길한 시간(낮) 시트 본문** `focus_time.day` (값은 시진 하나뿐, 일진과 태어난 해는 core 변경이 필요)
1. R37 그대로(중요한 일은 이 시간에 하면 좋아요.)
2. 오늘 일진과 내가 태어난 해를 보고 고른 시간이에요.
3. 오늘 일진 계미와 내가 태어난 해 경오를 보고 고른 시간이에요. (core 요청 뒤)
4. 다 별로

**R39-5 색이 둘인 날 첫째 색** `color.balance.*` (R37-1 문장, D123 ①이 그대로 두기로 한 표현)
1. R37 그대로(내 사주의 균형으로 보면 노랑이 잘 맞아요.)
2. 내 사주의 균형으로 보면 토 기운의 노랑이 잘 맞아요.
3. 내 사주의 균형이 오늘 노랑을 부르고 있어요. (대조군)
4. 다 별로

**R39-6 색이 둘인 날 둘째 색** `color.source.*` (R37-2 사용자 문구)
1. R37 그대로(원전의 해석에 따르면 오늘은 빨강도 어울려요.)
2. 원전의 해석에 따르면 토가 목욕 자리라 빨강도 어울려요.
3. 원전의 지혜가 오늘 빨강을 향해 미소 짓고 있어요. (대조군)
4. 다 별로

**R39-7 다시 묻기(R39-1, 순서를 바꿈)**
1. 내 사주의 기운이 오늘 노랑 속에서 빛을 찾아요. (대조군)
2. 토 기운이 오늘 지지에서 장생 자리라 노랑이 잘 맞아요.
3. 내 사주에 필요한 토 기운에 맞춰 오늘은 노랑이 잘 맞아요.
4. 다 별로
