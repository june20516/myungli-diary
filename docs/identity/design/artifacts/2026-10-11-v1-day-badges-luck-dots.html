귀인 sage-600/흰 글자 4.53:1 · 좋은 날 coral-600/흰 글자 4.89:1 · 기신 neutral-100/700 5.87:1 · 평범 테두리만, 글자 neutral-700 6.1:1 이상 (다크는 모두 7:1 이상)

캘린더 길흉 점 — 어느 쪽?

A

좋음 = 코랄 점 · 보통 = 없음 · 주의 = 회색 고리

달력이 가장 조용합니다. 점이 있는 날만 눈에 들어옵니다. 모양(채움/고리)으로도 구분되어 색약에도 안전합니다.

B

좋음 = 코랄 점 · 보통 = 옅은 점 · 주의 = 회색 고리

모든 날에 점이 있어 "계산된 날"이라는 게 드러납니다. 대신 화면이 조금 더 바쁩니다.

C

좋음 = 코랄 점 · 보통 = 없음 · 주의 = 회색 점(채움)

A와 같지만 주의를 채운 점으로. 모양 차이가 없어 색으로만 구분합니다.
