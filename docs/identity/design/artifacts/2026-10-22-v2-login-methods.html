로그인 수단 화면: "연결됨" 표시 세 안

예시 상태: 카카오와 Apple이 연결돼 있고 LINE·Google은 아직 연결하지 않았습니다(ko, 맨 위 제공자 카카오). 색·간격은 토큰 값 그대로이고, 로고 칸의 글자는 공식 자산이 들어갈 자리 표시입니다. 버튼 문구는 writing #388이 정합니다.

A. 연결된 것은 줄, 연결할 것은 버튼 (추천)

제공자 버튼을 손대지 않습니다. 연결된 수단은 settings-row 줄(로고 + 이름 + 떼기)이고, 아직 연결하지 않은 수단만 로그인 화면과 같은 브랜드 버튼으로 보입니다. 마지막 남은 하나는 "떼기" 대신 안내를 보입니다.

B. 네 버튼 그대로 + 연결됨 상태

로그인 화면과 같은 순서·모양의 버튼 네 개입니다. 연결된 버튼만 제공자 색을 빼고 중립 테두리 + "연결됨"으로 바뀌고, 누르면 떼기 확인이 열립니다. 익숙하지만 버튼 색을 바꾸는 것이 각 사 가이드와 어긋날 수 있습니다.

C. 네 줄 모두 settings-row

가장 조용합니다. 네 제공자를 한 묶음의 줄로 두고 오른쪽에 "연결됨 · 떼기" 또는 "연결"을 둡니다. 연결 동작이 브랜드 버튼이 아니게 되어 IA의 social-login-button을 이 화면에서 쓰지 않게 됩니다.
