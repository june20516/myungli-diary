origin과 다른 점

일기 쓰기 버튼 글자는 origin과 IA 가안대로 "일기 쓰기"이고, writing 원고 변경을 요청 중입니다. 일기 목록 미리보기는 V42대로 두 줄 말줄임이고, 카드 위에 날의 성격 태그를 더했습니다. 상단 바 가운데의 상태와 글자 수는 쉼표 대신 간격으로 나눴고(V47, V78), 상태 아이콘을 둡니다. 일기 쓰기 본문은 흰 종이(surface.paper) 위이고, 인용 질문은 종이 안 맨 위이고 글자는 본문(15)보다 작은 14입니다. 질문 바꾸기 아이콘을 질문 오른쪽에 두었습니다(spec §4). 2일 일기의 태그는 fixture가 충이지만 그날 己酉의 酉는 원국 지지와 충이 없고 일지 辰과 합이라, 명리에 맞게 합으로 그렸습니다(fixture 보정은 app에 요청).
