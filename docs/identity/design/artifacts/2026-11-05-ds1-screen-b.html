섹션 제목과 머리 글자는 UI 슬롯이라 바로 보이고, 요소마다 자기 skeleton을 화면 배치대로 놓습니다.

origin과 다른 점

대운 나이는 한국식 나이(core C22)로 적습니다. 올해와 지금의 줄 머리는 굵은 글자 대신 상태 꼬리표(지금, 올해)와 용어 칩(대운, 세운)이고, origin처럼 강조 바탕은 없습니다. 자주 붙은 태그는 한자 태그(사주 용어 초록)이고 수는 알약 안에 두며, 누르면 뜻 시트가 열리고, 시트 아래 꺾쇠 링크로 그 태그의 일기 모아보기로 갑니다(2026-11-06 개정). 행운 색 칩은 테두리 칩(V75)이고, 용신은 칩이 아닌 이름과 용어 칩입니다(사용자 승인 2026-11-06). 막대 트랙은 화면 바탕색입니다.
