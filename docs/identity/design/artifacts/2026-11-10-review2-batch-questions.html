Q1. 다시 묻기: 질문이 붙은 상태와 없는 상태 구분 (#929, D116)답: A 진한 선 / 선 없음, 떼기는 x

Q3. 탭 바로 탭을 바꿀 때의 전환 (#900)답: ③ 겹쳐 바뀜 200ms

지금은 탭을 누르면 한 프레임에 화면이 바뀌고 탭 도장만 움직입니다. 안쪽 화면 이동(page.push, 오른쪽에서 24px, 320ms)과 구분되게 방향 이동 없이 짧게 둡니다. 아래 탭을 눌러 보세요. 탭 도장(찍힘 520ms, 지워짐 200ms)도 실제 값으로 움직여 박자를 같이 볼 수 있습니다.

① 지금 (바로 바뀜)
전환 없음. 검수 회차2에서 효과가 없다고 지적받은 상태입니다.
② fade through 210ms권장
앞 화면이 60ms에 빠르게 사라지고, 새 화면이 150ms 동안 0.96배에서 제 크기로 커지며 나타납니다(enter 곡선). Material 하단 탭 관습이고 page.push보다 짧고 방향이 없습니다.
③ 겹쳐 바뀜 200ms
두 화면이 200ms 동안 서로 겹치며 투명도만 바뀝니다. 가장 조용하지만, 내용이 많은 화면끼리는 잠깐 두 화면이 겹쳐 보입니다.
④ 스밈 280ms
앞 화면이 80ms에 사라지고, 새 화면이 6px 흐림에서 또렷해지며 나타납니다(스밈 곡선, appear.seep 언어). 브랜드 느낌이 가장 크지만 길고, 화면 전체 흐림이라 저사양 기기에서는 투명도만 남깁니다.

동작 줄이기를 켜면 모든 안이 투명도만 남습니다(V14). 이미 선택된 탭을 다시 누르면 전환 없이 맨 위로 올라가는 지금 규칙은 그대로입니다.

Q5. 맨 아래 버튼과 화면 아래 끝 사이 (#918 ②)답: ② inset + 16

알림 허락 화면처럼 아래에 버튼이 붙은 화면입니다. 시스템 inset(Android 3버튼 48, 제스처 막대 24, 없음 0, iPhone 홈 막대 34) 위에 더하는 값을 고릅니다. 버튼 사이 간격(16)은 지금이 좋다고 하셔서 그대로입니다. 빨간 숫자는 '나중에' 버튼 면 아래 끝에서 시스템 영역까지입니다. 투명 버튼은 면이 보이지 않아 로 확인할 수 있습니다.

같은 값을 아래 고정 버튼 전체(input-step 아래 버튼, 버튼 하나뿐인 화면 포함)에 씁니다. 목록 위에 떠 있는 버튼과 toast는 이미 "아래 안전 영역 위 16"이라 ②를 고르면 앱 전체가 한 값이 됩니다. 키보드가 열리면 키보드 위 16입니다.
