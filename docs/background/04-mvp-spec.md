# 4. MVP (Minimum Viable Product) 명세

**MVP 목표:** 명리 엔진의 정확성 검증과 사용자의 핵심 경험(데일리 운세 확인 + 일기 작성) 가설 테스트

## 4.1. 온보딩 및 유저 세팅
* 생년월일시 입력을 통한 메인 사주 데이터 생성 (Python 엔진 연동).
* 유저 계정 생성 및 기본 인증 (소셜 로그인 1~2개 지원).

## 4.2. 메인 화면 (데일리 추천 - Easy 모드 중심)
* 복잡한 역학 용어는 배제하고 직관적인 텍스트 위주로 UI 구성.
* "오늘의 행운 컬러", "오늘 집중하기 좋은 시간", "행운의 방향" 카드 제공.

## 4.3. 명리일기 (기본 작성 및 저장)
* 텍스트 기반 일기 작성 및 클라우드(PostgreSQL) 저장.
* 일기 작성 완료 시 해당 일진의 핵심 명리 데이터(예: #식상다발) 자동 해시태그 부여.

## 4.4. 기본 캘린더 뷰
* 한 달 단위 달력에 길일/흉일만 색상 점으로 단순 표기.
* (목적별 택일 필터 및 외부 캘린더 연동 기능은 MVP 이후 2차 스펙으로 이관하여 개발 속도 확보).
* 개정(D47): MVP에 기본 일정(제목·날짜·종일 또는 시간·메모)을 넣습니다. 반복·일정 알림·외부 캘린더 연동은 2차입니다.
