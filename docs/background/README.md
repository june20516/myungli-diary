## 문서 간 관계
* `03-app-prd.md`는 `00-product-spec.md`의 요약판입니다.
  * 03에서 추가된 것: "삶의 패턴 파악" 목적, Easy 모드 / Pro 모드 명칭.
  * 03에서 빠진 것: 외부 캘린더 연동, Easy/Pro JSON 응답 구조. 이 둘은 01·02에 정의되어 있습니다.
* 기능별 상세 기준(예: 목적별 택일 조건)은 `00-product-spec.md`를 따릅니다.
* `04-mvp-spec.md`는 00~03의 전체 범위 중 1차 개발 범위를 정하고, `05-roadmap.md`는 그 나머지를 Phase별로 배치합니다.
* `06-design-system.md`는 00·03의 Easy/Pro 원칙을 UI로 구체화합니다.
  * 디깅 3단계: Surface(카드) → Digging 1(바텀시트 Half) → Digging 2(바텀시트 Full).
  * 오행 5색 팔레트가 옷 색깔 추천과 캘린더 길흉 점에 공통으로 쓰입니다.
* `07-engine-logic-wiki.md`는 00 §3.1~3.4의 명리 로직을 수치·조건식으로 구체화합니다. 엔진 구현 시 연산 기준은 07을 따릅니다.
  * 00 §3.3 목적별 택일 → 07 §4.2 배점표 (00의 "결혼"은 07에서 "연애"만 정의됨)
  * 00 §3.4 명리 태깅 → 07 §4.3 해시태그 우선순위·동점 룰

## 07 엔진 위키 검토 메모 (v1.4 기준)

### 해결됨 (v1.1~v1.4 반영)
* 시차 보정 이중 적용 → 보정한 시각 기준 23:00 경계로 확정 (07 §2.2·§2.3)
* 30분 고정값의 한계 → 출생지는 받지 않고, 역사적 표준시·서머타임은 `zoneinfo` `Asia/Seoul`로 처리 (07 §2.2)
* 매핑 튜플 키 순서 → `frozenset` 키로 바꾸거나 정렬 후 조회하도록 명시 (07 §5)
* 레퍼런스 보강 → 용신 이론 근거, 조후용신표, 참고 구현체 추가 (07 §3.3·§5·§6·§7)
* 용신 산출 방식 → 조후 우선 판정 + 억부 기본으로 확정 (07 §3.3-0)
* 조후용신표 전수 대조 → 120칸 대조 완료, 11칸 정정 (07 §5, `docs/references/gungtong-bogam/`)
* 만세력 라이브러리 → lunar-python(MIT) + 한국 시각 변환 계층 직접 구현 (07 §2.1)
* 서울 지방평균시 보정값 → -30분(동경 127.5°, 국내 관례) 확정 (07 §2.2)
* 자시 처리 → MVP 기본값은 자시 통합 방식, 앱 안에 기준 안내 (07 §2.3)
* 정확성 검증 기준 → KASI + 기준 앱 2개, 2단계 검증 (07 §8)

### 미결
1. 조후 판정 기준값 (화·수 비중) (07 §3.3-4)
2. 신강·신약 판정 임계값, 위치별 가중치(v1.0 안과 참고 구현체 중 선택), 지장간 비율표 출처 (07 §3.1·§3.3-4)
3. 합화 조건의 "인접" 범위, 택일 점수 적용 방식과 길흉 판정 임계값, 해시태그 전체 목록 (07 §3.2·§4)
