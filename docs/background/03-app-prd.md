# 3. 구체적인 앱 제품 PRD

## 3.1. 서비스 개요
* **서비스명:** 명리일기 (Myungli Diary)
* **서비스 목적:** 사주 명리학과 역리학을 바탕으로 매일매일 각종 소소한 운세나 옷 색깔, 방위, 시간 등을 추천하고, 하루를 마무리할 때 일기를 남겨 삶의 패턴을 파악하게 해주는 애플리케이션.
* **핵심 타겟:** 명리학 콘텐츠를 가볍게 소비하고자 하는 일반 대중부터 사주 데이터를 활용해 적극적으로 스케줄을 관리하려는 역학 관심층.

## 3.2. 핵심 가치 및 UX 설계 원칙
* **점진적 정보 노출 (Progressive Disclosure):** 일반 사용자도 쉽게 즐길 수 있도록 1차적으로는 매우 직관적이고 쉬운 문장 형태의 결과를 제공(Easy 모드). 동시에 사용자가 흥미를 느끼고 터치/스와이프 할수록 오행, 십성, 합충변화 등 명리학의 상세 데이터를 탐구할 수 있는 자연스러운 디깅(Digging) 구조 채택(Pro 모드).

## 3.3. 주요 기능 명세
1. **만세력 기반 사주 추출:** 사용자의 생년월일시를 입력받아 60갑자 기준의 사주팔자와 대운 및 세운을 정확히 뽑아내는 알고리즘.
2. **데일리 맞춤 운세 및 추천 시스템:**
   * **의상/소품 추천:** 용신과 희신의 오행을 파악하여 옷 색깔, 액세서리, 행운의 숫자 추천.
   * **방위 및 시간 추천:** 오늘의 일진과 사주를 대조해 유리한 귀인이 위치한 방위나, 흉살이 없는 시간대를 계산.
3. **맞춤형 캘린더 및 택일 시스템:**
   * **길일/흉일 판별:** 사주 구조와 일진의 합충을 계산하여 캘린더상에 직관적으로 길흉 표시.
   * **목적별 택일:** 이사, 연애/결혼, 재물/계약 등 사용자의 스케줄 목적별로 가중치를 다르게 적용.
4. **명리일기 및 회고 시스템:**
   * **일기 작성/피드백:** 아침에 그날의 명리적 특징을 알려주고, 일기 작성 시 가이드 질문이나 감성적 코멘트 제공.
   * **명리 데이터 태깅:** 일기 저장 시 내부 연산된 명리적 특징(#도화살, #재성 등)이 자동 해시태그로 붙으며, 클릭 시 과거 기록 회고 지원.
