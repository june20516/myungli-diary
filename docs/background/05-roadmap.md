# 5. 제품 로드맵 (Roadmap)

## Phase 1: 기반 구축 및 MVP 런칭 (M1 ~ M3)
* Flutter 클라이언트(UI/UX 뼈대) 및 Go 메인 서버 인프라 구축.
* Python 명리 엔진 서버 개발 및 만세력/음양오행 알고리즘 이식.
* MVP 핵심 기능(사주 추출, 데일리 텍스트 운세, 해시태그 일기, 기본 캘린더) 개발.
* 앱스토어 (iOS / Android) 최초 심사 및 런칭.

## Phase 2: UX 고도화 및 확장 기능 추가 (M4 ~ M6)
* **점진적 정보 노출 UI 본격 적용:** 바텀시트, 툴팁을 통한 'Easy -> Pro 모드' 디깅(Digging) 경험 및 사주 엑스레이 시각화 도입.
* **캘린더 기능 강화:** 이사, 계약, 연애 등 캘린더 목적별 택일 필터링 기능 추가.
* **외부 연동 오픈:** 구글 캘린더 및 애플 캘린더 동기화 지원.
* **SNS 바이럴 최적화:** Flutter 캔버스 캡처를 활용한 오늘의 운세/일기 인스타그램 스토리, 카카오톡 템플릿 공유 기능 런칭.

## Phase 3: 커뮤니티 오픈 및 생태계 확장 (M7 ~ M9)
* **소셜/커뮤니티 기능:** 자신과 비슷한 사주(예: 동일한 용신)를 가진 유저들끼리 팁을 나누거나 익명으로 일기를 공유하는 커뮤니티 피드 오픈 (Go 서버 활용 극대화).
* **디바이스 다각화:** 스마트워치(Apple Watch, Galaxy Watch) 연동을 통한 골든타임/주의 시간대 푸시 알림 제공.
* **수익화 모델 도입:** 전문가 수준의 상세 연운/대운 리포트 프리미엄(In-App Purchase) 구독 모델 적용 검토.
