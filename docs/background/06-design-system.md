# 명리일기 디자인 시스템 (Design System) 펀더멘탈

## 1. 핵심 UX 원칙: 점진적 정보 노출 (Progressive Disclosure)
명리일기는 명리학을 가볍게 즐기는 일반 대중부터 적극적으로 스케줄을 관리하려는 역학 관심층까지 폭넓은 타겟을 만족시키기 위해 '점진적 정보 노출'을 디자인의 핵심 원칙으로 삼습니다.

*   **Easy 모드 (Surface):** 메인 화면은 복잡한 역학 용어를 배제하고 직관적인 텍스트 위주로 구성합니다. "오늘의 행운 컬러", "행운의 방향" 등을 카드 형태로 심플하게 보여주어 일반 사용자도 심리적 부담 없이 가볍게 즐길 수 있도록 디자인합니다.
*   **Pro 모드 (Digging):** 사용자가 흥미를 느끼고 터치나 스와이프(Swipe)를 할 때, 툴팁과 바텀시트(Bottom Sheet)를 활용하여 음양오행, 천간지지, 십성, 합충변화 등의 상세 명리 데이터를 탐구할 수 있는 디깅(Digging) 구조를 설계합니다. 

### 디깅 인터랙션 (바텀시트 활용)
바텀시트는 사용자의 맥락(Context)을 유지하며 언제든 메인 화면으로 돌아올 수 있는 안정감을 주며, 제스처에 따라 정보의 깊이를 조절하기에 최적화된 컴포넌트입니다.

*   **Surface:** 메인 카드뷰 ("오늘은 초록색 계열의 옷이 인간관계에 부드러움을 더해줄 거예요")
*   **Digging 1 (Half View):** 바텀시트 절반 확장 ("오늘은 나를 도와주는 나무(木)의 기운이 꼭 필요한 날이거든요")
*   **Digging 2 (Full View):** 바텀시트 전체 확장 (오행 밸런스 그래프, 사주 엑스레이 시각화 등 상세 역학 리포트 제공)

## 2. 컬러 시스템: 현대적인 오행(五行) 팔레트
사주에서 가장 필요하고 이로운 기운인 용신(用神)과 희신(喜神)의 오행을 시각화하기 위해, 전통적인 오방색을 현대적이고 부드러운 라이프스타일 톤으로 재해석하여 브랜드 컬러 팔레트를 구축합니다. 이 컬러들은 데일리 운세의 옷 색깔 추천이나 캘린더의 길일/흉일 색상 점 표기 등 앱 전반에 일관된 룰로 적용됩니다.

*   **Wood (목 - 초록 계열):** 편안함과 성장을 상징하는 차분한 세이지 그린 (Sage Green)
*   **Fire (화 - 붉은 계열):** 활력과 열정을 나타내는 부드러운 코랄 핑크 (Coral Pink)
*   **Earth (토 - 노란/갈색 계열):** 안정감을 주는 웜 샌드 베이지 (Warm Sand Beige)
*   **Metal (금 - 흰색/은색 계열):** 결단력과 깔끔함을 보여주는 오프화이트 (Off-White)와 라이트 그레이 (Light Gray)
*   **Water (수 - 검은/푸른 계열):** 지혜와 유연함을 상징하는 딥 네이비 (Deep Navy)와 뮤트 블루 (Muted Blue)

## 3. 타이포그래피 위계 (Typography Hierarchy)
텍스트의 성격에 따라 위계를 명확히 나누어 가독성을 높이고 정보의 깊이를 시각적으로 분리합니다.

*   **Easy 텍스트 (위로 및 코멘트):** 가독성이 높고 둥근 고딕 폰트를 사용하여 감성적이고 부드러운 톤앤매너를 전달합니다.
*   **Pro 파라미터 (원시 명리학 데이터):** 바텀시트 내의 전문 역학 용어는 볼드(Bold)한 가중치를 주어 일반 텍스트와 시각적으로 명확히 분리되게 디자인합니다.

## 4. 핵심 UI 컴포넌트
*   **캘린더:** 한 달 단위 달력에 길일과 흉일을 색상 점(Dot)으로 단순 표기하는 UI 컴포넌트. (추후 목적별 택일 필터링을 위한 아이콘 셋 확장 예정)
*   **명리일기 해시태그 칩 (Chip):** 일기 작성 후 자동으로 부여되는 명리 데이터(예: #도화살, #재성 등)를 감각적인 칩 형태로 규격화하여 회고 기능으로의 진입을 유도합니다.

## 5. 소셜 공유 템플릿
*   Flutter의 캔버스 캡처 기능(RenderRepaintBoundary)을 활용하여 앱 화면을 캡처해 인스타그램 스토리나 카카오톡으로 공유할 수 있는 '오늘의 운세 카드' 및 '명리일기 요약' 이미지 템플릿을 심미적으로 디자인합니다.
