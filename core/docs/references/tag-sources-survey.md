## 살펴봤지만 쓰지 않은 것
* **『子平真詮』(월령 중시):** 위키문헌에 문서가 없습니다(검색해도 나오지 않음). 같은 뜻은 『滴天髓』 「月令論」으로 확인했습니다.
* **『淵海子平』:** 위키문헌 문서에 `{{No source}}` 틀이 붙어 있어 판본을 알 수 없습니다. 같은 조목이 『三命通會』에 있어 쓰지 않았습니다.
* **『滴天髓』 「地支論」 "地生天者，天衰怕沖。"(`jeokcheonsu/ch03.wikitext`):** 일지 충을 직접 말하지만, 일지가 일간을 생하고 일간이 약할 때로 조건이 좁습니다. 엔진의 일지 충 태그는 그 조건을 보지 않으므로 대표 근거로 쓰지 않았습니다. 같은 문서의 "支神祇以沖為重"도 후보였으나 연지·시지 충까지 포괄하는 『三命通會』 「论冲击」을 썼습니다.
* **『三命通會』 「论年月日时」 "况用神多取诸月，是月又可轻乎？":** 월지의 무게를 말하지만 「月令論」이 더 직접적입니다.
